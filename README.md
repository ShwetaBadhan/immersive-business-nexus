# PAGE TRANSITIONS

This is extremely important.

Never instantly switch pages.

When navigating:

1. Current 3D world begins to distort.
2. Camera moves forward.
3. Green particles expand.
4. Screen briefly becomes dark green.
5. New scene emerges.
6. Typography reveals itself.
7. New page becomes interactive.

Transition duration:

approximately 800–1200ms.

Everything must be smooth.

---
